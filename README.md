# 船舶轮机值更工作台

面向轮机员交接班的前端记录系统：选定班组开工，写入四类机舱参数，逐台勾选巡检；
参数冲过安全界限或巡检勾异常时自动生成未结事项，闭环处理后才能交班；
交班记录归档只读，新异常仍可补登到遗留列表，由下一班自动并入。数据只保存在本机浏览器。

## 业务规则

1. **选定班组开工**：08–12 / 12–16 / 16–20 三个班组；开工后遗留未结事项自动并入本班。
2. **四类参数**：主机转速、滑油压力、冷却水温、燃油消耗。读数越过安全上下限即生成未结事项，回到安全区间自动销项。
3. **逐台巡检**：每台设备勾选「正常 / 异常」，勾异常生成未结事项。
4. **未结事项闭环**：处理人、复测读数、备注三项缺一项，「标记完成」不可用。
5. **交班确认**：四项参数填齐、巡检逐台勾选、本班无未结事项，三个条件同时满足才可交班；摘要中逐台提示阻塞项。
6. **归档只读**：交班后记录只能翻阅，不能再改；支持按设备筛选历史。
7. **遗留列表**：归档期间发现的新异常可随时补登，进入遗留池，下一班开工自动并入并继续阻塞交班。
8. **本机存储**：全部数据存于浏览器 `localStorage`，不联网上传。

## 结构（三层拆开维护）

```
src/
├── definitions/
│   └── parameters.ts     # 参数定义：四类参数安全界限、巡检设备项、班组
├── state/
│   ├── constants.ts      # 状态取值（watch / issue / check 状态机常量）
│   ├── reducer.ts        # 状态流转：recording→handed、open→resolved 及各记录动作
│   ├── utils.ts          # 纯函数：读数判定、交班阻塞项计算等
│   ├── storage.ts        # localStorage 读写
│   ├── seed.ts           # 示例归档（演示只读）
│   └── store.tsx         # Context + useReducer，自动持久化
├── components/           # 界面层：班组条、参数看板、巡检清单、事项面板、交班摘要、归档
├── types.ts              # 领域类型
└── App.tsx
```

调整安全界限/设备班组只改 `definitions`；调整状态流转规则只改 `state/reducer.ts`；
调整页面只改 `components`，互不耦合。
