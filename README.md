# hxyfront-62001 机舱值更工作台

面向船舶轮机值班的前端记录系统。轮机员选定班组开班后，逐台填报四类机舱参数、勾选巡检结果；参数冲过安全界限或巡检异常会自动生成未结事项；交接、归档、遗留跨班闭环。数据仅保存在本机浏览器。

## 工作台流程

1. **选定班组开班**：班组 + 日期 + 班次时段；同时只允许一个值更班次，开班时自动并入遗留未销项。
2. **四类参数填报**：主机转速、滑油压力、冷却水温、燃油消耗（按主机/发电机分组），读数越出安全界限立即生成未结事项。
3. **逐台巡检勾选**：按设备逐台勾「正常 / 异常」，勾异常自动生成事项并可补充现象。
4. **未结事项处置**：处理人、复测读数、处理备注缺一项不能点完成；参数越限还要求复测值回到界限内。处理不完可填交接说明移交遗留。
5. **交班确认**：本班存在任何未结事项时按钮不可用，摘要按设备逐台列出未结项；确认后归档封班，归档内容只读翻阅。
6. **遗留登记**：归档后发现的新异常可随时登记并入遗留列表，下一班开班自动带入；遗留事项在本班完成会同步销项。
7. **历史归档**：按设备筛选翻阅历史班次的参数、巡检与事项。

## 分层结构（拆开维护）

```
src/
├── domain/
│   ├── types.ts        # 领域模型（仅类型）
│   ├── definitions.ts  # 参数定义：班组、设备、安全界限、巡检项（改界限只改这里）
│   └── engine.ts       # 状态流转：纯函数 reducer + 完成/交班校验规则（不依赖 React）
├── services/
│   └── storage.ts      # 本机 localStorage 持久化
├── state/
│   └── useWatchStore.ts  # React 与状态机的唯一接缝
├── components/         # 界面层（开班、参数看板、巡检、事项、交班、遗留、历史）
└── App.tsx
```

数据只保存在浏览器 localStorage（键：`engine-watch-console-v1`），不发往任何服务器；顶栏可一键清空本机数据。
